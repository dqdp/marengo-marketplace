# Данные через Marengo

Этот skill — необязательная помощь в выборе коннектора. Данные доступны через стандартные MCP-инструменты и без skill. Он не устанавливает подключение, не создаёт аккаунт и не задаёт обязательную методику анализа.

## Найти доступную возможность

Используй фактически объявленные инструменты выбранного Marengo-подключения. Если доступны `marengo_platform_catalog` и `marengo_platform_describe`, найди возможность в каталоге и прочитай её описание/schema перед вызовом. Имена аргументов бери из текущей схемы discovery-инструмента.

Capability ID записывается через точки; canonical tool name следует форме `marengo_<connector>_<domain>_<action>`. Конкретные идентификаторы и имена копируй из discovery. Не угадывай tool name по шаблону, названию поставщика или инструкции старой версии. Совместимый alias выполняет ту же операцию — повторный вызов canonical после alias не нужен.

Каталог ограничен правами пользователя. Различай объявленную возможность, наличие credentials, доступность источника и успешный вызов: одно не доказывает другое. Если discovery ещё отсутствует в установленной версии, ориентируйся на доступные MCP tools и их schemas; наличие этого skill не доказывает развёртывание новой версии Gateway.

## Иерархия и выбор источника

| Компонент | Как использовать |
|---|---|
| Marengo Platform | Общая авторизация, личные credentials, discovery и рабочий кэш коннекторов |
| COT connector | Позиционные и связанные данные; Socrata, FMP и LSEG — вложенные upstream-источники COT, а не отдельные коннекторы платформы |
| Databento connector | Futures и options on futures, схемы и операции Live/Historical, которые объявлены конкретным сервером |
| Alpha Vantage MCP | Отдельное подключение со своими tools/credentials; в состав Marengo не входит |

Для COT и связанных Socrata/FMP/LSEG запросов исследуй возможности **COT**, включая состояние нужного upstream. Для futures/options on futures исследуй Databento. Список источников не доказывает готовность их ключей, лицензии и данных. Если пользователь явно выбирает источник, сохраняй этот выбор; недоступность не является разрешением незаметно заменить его.

При запросе Alpha Vantage используй только его отдельно подключённый MCP. Если такого подключения нет, сообщи это; не ищи воображаемую Alpha Vantage capability в Marengo. Equity/ETF options и options on futures различаются — уточняй рынок, только если его нельзя определить из запроса и символа.

## Выполнить запрос

В удалённом режиме получай данные через авторизованный Marengo MCP. Не запускай локальные producer/Python/Node scripts, shell helpers, прямые HTTP/TCP-вызовы поставщика и не читай локальные `.env`, профили или API keys. Это правило сохраняется при отсутствии remote tool, ошибке доступа или timeout. Ключ пользователь сохраняет в личном кабинете сервиса; не запрашивай его в чате или tool arguments.

Выбирай минимальные достаточные dataset, symbols, schema, период и объём из запроса пользователя и актуальной схемы инструмента. Для истории учитывай доступные границы каждого schema; для текущего состояния выбирай фактическую Live-возможность, если она доступна. Описание права или подписки не заменяет успешное получение нужных данных.

Для одной котировки запроси объявленную возможность Live get_futures_quote. Для потока лучших bid/ask и объёмов найди в каталоге Live stream_bba. Используй один stream_id между start, последовательными read по next_cursor и stop. При пропуске сообщи missed_events. Сохраняй отдельно время биржевого события и время получения. Если сервер объявил только однократную котировку, постоянный поток на этом подключении недоступен.

Для поиска по названию, экспирации, типу опциона и страйку используй объявленный instruments.search. Уточни семейство при неоднозначности. При нескольких подходящих сериях покажи варианты. Для уникального совпадения передавай instrument_id строкой в Live. При частичном покрытии обозначай ближайшую серию как ближайшую среди найденных.

Для списка контрактов и их параметров найди instruments.list или объявленный Historical get_range со схемой definition. Семейство выбирай по родительскому символу, конкретную серию — по raw_symbol или instrument_id. Укажи интервал UTC и предел выборки. Учитывай биржу, класс инструмента, изменения определения и полноту ног спредов.

Для historical покрытие Standard привязано к текущему ключу и серверной политике. Внутри подтверждённого покрытия не добавляй собственный автоматический `get_cost`; вне покрытия любая положительная оценка требует разового подтверждения в кабинете. Не объявляй назначенный план проверенным биллингом поставщика. При `confirmation_required` передай сведения об операции/подтверждении и не повторяй вызов автоматически. Технические лимиты, лицензия и права остаются обязательными.

## Представить результат

Сохраняй названия источника/dataset/schema, instrument identity, период, времена и provenance из ответа. Не смешивай futures с options, COT FO с Combined, категории разных отчётов или standard/mini/micro. Не заменяй ICE Brent контрактом NYMEX BZ либо LME prices спотовым бенчмарком без явного запроса. Отсутствие/подавление данных отмечай причиной, а не нулём.

Для продолжения, страниц, оригиналов и экспорта используй доступные операции рабочего кэша и идентификаторы ответа. Не придумывай Research Storage, research revisions или облачные `research_*` возможности. Платформа не исполняет загруженный пользовательский код.

Дальнейший анализ, формулы, отчёт и визуализация определяются запросом пользователя. Не требуй фиксированного промпта, торговли по регламенту, обязательного отчёта/dashboard или сохранения исследования для получения данных. Если задача закончилась получением данных, на этом её можно завершить.
