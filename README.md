# Marengo Market Data

Приватный каталог скилла для ChatGPT Work и Claude Cowork. Обе поставки собираются из одного коммита приватного Market Data Skill. Версия, исходный коммит и контрольные суммы файлов хранятся в [release.json](release.json).

## Первое подключение

Клиентская редакция с обычными ценовыми графиками находится в `editions/price-charts` приватного `dqdp/market_data_skill`. Основа графиков и расчёта греков — версия 1.36.0, коммит `753c19b`. Номер поставки 1.169.2 позволяет обновить полную версию 1.168.0. Каталог включает только маршрутизатор, справочник Alpha Vantage, построение ценового SVG и расчёт греков.

Пользователю личного аккаунта нужен доступ на чтение приватного каталога `dqdp/marengo-marketplace`. Каталог содержит файлы скилла, поэтому отдельный доступ к репозиторию разработки для установки не требуется.

**ChatGPT Work на компьютере.** На машине пользователя с настроенным GitHub SSH и Codex CLI добавьте каталог командой `codex plugin marketplace add git@github.com:dqdp/marengo-marketplace.git --ref main`. Перезапустите настольный ChatGPT, откройте каталог плагинов в режиме Work, выберите Marengo и установите Marengo Market Data. Обновить локальную копию каталога можно командой `codex plugin marketplace upgrade marengo`. Перезапустите приложение и проверьте версию установленного плагина. [Документация OpenAI](https://developers.openai.com/plugins/build/plugins#add-a-marketplace-from-the-cli)

**Claude Cowork.** В разделе Customize → Plugins выберите Add marketplace → Add from a repository, укажите `dqdp/marengo-marketplace` и установите Marengo Market Data. Для приватного каталога подтвердите доступ к GitHub. [Инструкция Anthropic](https://support.claude.com/en/articles/13837440-use-plugins-in-claude)

При переходе с ручного ZIP проверьте версию плагина в новой сессии и отключите прежний вручную добавленный market-data. Если ZIP распаковывали в личную папку skills, перенесите старую папку market-data за пределы каталогов обнаружения. Проверьте, что в новой сессии видна одна редакция.

**Подключение данных на чистом компьютере**

1. Добавьте HTTPS MCP Marengo `https://mcp.marengo.net/mcp` в настройках коннекторов клиента. Войдите через OAuth под приглашённой учётной записью Marengo. Личный ключ Databento сохраняется в кабинете Marengo. Откройте каталог инструментов Marengo в новой сессии.
   Для личного Codex с уже добавленным сервером команда входа с продлением — `codex mcp login marengo --scopes data:read,offline_access`. Если клиент использует фиксированные OAuth scopes, добавьте `offline_access` к существующему списку в настройках Marengo. Для чтения котировок достаточно права ресурса `data:read`. В ChatGPT Work и Claude Cowork разрешения и хранение токена зависят от самого клиента. Для приёмки один раз войдите в каждом клиенте, закройте его, затем после истечения исходного access token откройте новую сессию и вызовите `marengo_platform_catalog`. Запишите результат проверки и факт запроса согласия. Значения токенов в отчёт не включайте. [Настройки refresh token в Logto](https://docs.logto.io/integrate-logto/application-data-structure)

2. Для MOEX выпустите в БКС Trade API refresh-токен с правом «Только для чтения». В настольном ChatGPT откройте Настройки → Интеграции → Плагины → Добавить сервер MCP. Выберите HTTP и адрес `https://be.broker.ru/trade-api-mcp-server/mcp`. В Claude Desktop откройте Settings → Connectors → Add custom connector и задайте тот же адрес. Для интерфейса с секцией Request headers выберите No sign-in. Укажите в настройках подключения заголовок `Authorization` со значением `Bearer <refresh-токен>`. Если секция заголовков недоступна, используйте способ установки для своей ОС из официальной инструкции. Откройте новую сессию Work или Cowork и проверьте доступность инструментов БКС. [Инструкция БКС для обоих клиентов](https://trade-api.bcs.ru/mcp/)
3. Подключите существующий Alpha Vantage MCP с прежней авторизацией. В новой сессии запросите котировку SPY через Alpha Vantage, ценовой график CME через Marengo и bid/ask SBER через БКС. Для каждой проверки сверьте источник, инструмент и время котировки. Вне торговой сессии зафиксируйте время последнего обновления.

 После установки проверьте маршруты данных в новой сессии: CME через Marengo, текущие котировки MOEX через БКС, акции США и ETF через Alpha Vantage.

## Публикация обновления

1. Повысьте `version` в `editions/price-charts/SKILL.md`, проверьте изменение и отправьте исходный коммит в GitHub.
2. Оператор с доступом к обоим репозиториям запускает из копии каталога `python3 tools/propose.py ПОЛНЫЙ_SHA`. Используются обычные git/SSH и gh оператора. Команда собирает обе версии в отдельной временной папке и открывает PR в каталог. Повтор возвращает существующий PR или статус уже опубликованного SHA.
3. Проверьте CI и изменения, затем объедините PR в `main`. Обновите каталог на клиентском устройстве и сверьте версию плагина с release.json.
4. В каждом клиенте откройте новую сессию, проверьте установленную версию и запросите котировку по известному инструменту. Для возврата к прежней логике выпустите исправление с новым номером версии.

Локальная проверка каталога выполняется командой `python3 tools/release.py`. Для сверки с исходниками используйте `python3 tools/release.py --check-source /path/to/market_data_skill`.
