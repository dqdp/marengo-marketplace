# Рыночные данные и ценовые графики

Определи биржу, класс актива, валюту и нужный момент времени. Уточни неоднозначный тикер. Проверяй доступные инструменты и их схемы на текущем подключении.

## Фьючерсы и опционы CME

В Marengo открой marengo_platform_catalog и marengo_platform_describe. Для поиска по названию продукта, дате экспирации, типу опциона и страйку используй marengo_databento_instruments_search. Для списка контрактов семейства и параметров инструмента используй marengo_databento_instruments_list. Перелистывай сохранённые результаты по возвращённому курсору. При provider_limit_reached пустая выдача может быть неполной. Для поиска по частям следуй narrower_windows и инструкции ответа по сведению исходных A/M/D перед выбором nearest. При подтверждении расходов повторяй с возвращёнными retry_arguments. Сохраняй биржу, символ, ID, единицу контракта, шаг цены и экспирацию.

Для разовой котировки используй marengo_databento_live_get_futures_quote. При выборе по ID передай ID строкой и stype_in=instrument_id. Для потока лучших bid/ask используй marengo_databento_live_stream_bba по его текущей схеме: start, последовательные read по next_cursor, затем stop для того же stream_id. Укажи пропуски missed_events. Пустое чтение при закрытом рынке не даёт новой котировки.

Исторические бары запрашивай через доступную операцию Marengo для OHLCV. Используй покрытие и решения о расходах, возвращённые сервером. При confirmation_required направь владельца в кабинет. При отсутствии прав, подключения или данных сообщи причину. Для опционных греков по запросу доступен scripts/greeks.py (Black-76 для фьючерсных опционов). Указывай входные параметры, время цен и происхождение расчёта.

## Московская биржа

Для текущих котировок используй подключение БКС и его операции чтения. Сопоставь инструмент и режим торгов. Покажи отдельно bid, ask, последнюю сделку и время источника по доступности. Для истории используй доступные исторические свечи БКС либо MOEX ISS с указанием источника. Снимок ISS явно пометь как задержанный. При запросе только live и отсутствии свежих данных БКС сообщи об этом.

## Alpha Vantage

Акции США, ETF, опционы на акции и ETF, FX, криптовалюты и фундаментальные данные запрашивай через прежний отдельный Alpha Vantage MCP. Например, SPY и опционы SPY идут сюда, а фьючерсы ES и опционы на ES — в Marengo. Справочник поставщика находится в references/alpha-vantage.md. Доступность операций и права на realtime проверяй по текущему подключению и ответу поставщика.

## Ценовой график

Получи исторические свечи выбранным выше маршрутом. Сохрани реальные строки OHLCV в CSV с полями timestamp,open,high,low,close,volume. Приведи цены к денежным единицам согласно схеме источника. Время приведи к UTC (YYYY-MM-DD HH:MM:SS), а для дневных свечей сохрани дату торговой сессии. Используй только доступный интервал или агрегируй более частые свечи. Укажи источник, часовой пояс, диапазон, пропуски и задержку.

Запусти приложенный скрипт из папки скилла, подставив фактические символ, путь к данным, интервал и подпись источника:

```sh
python3 scripts/chart.py SYMBOL --from bars.csv --source-label "SOURCE · UTC" --interval 1d --out price.svg
```

На Windows можно использовать py -3. Передай пользователю полученный SVG. Скрипт рисует ценовые свечи, объём при наличии и SMA-20 при достаточной истории. Для графика достаточно свечей из коннектора, ключи на машине пользователя не требуются. Если среда не позволяет выполнить Python, верни свечи и укажи ограничение построения.
