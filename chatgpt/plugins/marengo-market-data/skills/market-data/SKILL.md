# Рыночные данные и ценовые графики

Определи биржу, класс актива, валюту и нужный момент времени. Уточни неоднозначный тикер. Если пользователь назвал поставщика, обращайся к нему. Если у него нет нужных данных, сообщи причину и согласуй смену источника. Проверь операции и права на выбранном подключении. Для Marengo начни с `marengo_platform_catalog` и `marengo_platform_describe`.

## Биржевые опционы США

Если источник не указан, для текущего национального лучшего bid/ask (NBBO), размеров и истории котировок по индексным опционам (SPX, NDX, RUT), опционам на ETF (SPY, QQQ) и отдельные акции (AAPL) используй Marengo Databento, dataset `OPRA.PILLAR`. Для готовой цепочки опционов на акцию или ETF, греков и IV поставщика используй доступные опционные методы Alpha Vantage. Если для запрошенного индексного опциона у источника нет данных, сообщи это. Опцион на ETF — отдельный контракт.

Если известен точный OCC `raw_symbol`, сразу передай его в `marengo_databento_live_get_futures_quote` для одного двустороннего обновления. Сохрани корень серии и пробелы в шестипозиционном поле корня. Если серию ещё предстоит подобрать, найди её по экспирации, call/put и страйку в определениях OPRA через `marengo_databento_instruments_list`. Возьми оттуда OCC-символ. У OPRA числовые ID в Live и Historical могут различаться. Пример аргументов Live для известной серии приведён ниже.

```json
{"dataset":"OPRA.PILLAR","symbol":"SPX   261218P05425000","stype_in":"raw_symbol"}
```

Сервер выбирает `cmbp-1` автоматически. Покажи bid/ask, размеры и время события. Когда в пределах тайм-аута обновление не пришло, укажи это. Поток `marengo_databento_live_stream_bba` доступен для CME `GLBX.MDP3`.

Для истории проверь границу нужной схемы через `marengo_databento_metadata_get_dataset_range`. Вызови `marengo_databento_historical_get_range` для того же OCC-символа в пределах архива. Выбери `cbbo-1s` для секундных срезов или `cmbp-1` для событий. Укажи интервал и фактическое время данных. При `confirmation_required` передай владельцу запрос на согласование стоимости.

## Фьючерсы и опционы CME

Для поиска по названию продукта, дате экспирации, типу опциона и страйку используй marengo_databento_instruments_search. Для списка контрактов семейства и параметров инструмента используй marengo_databento_instruments_list. Перелистывай сохранённые результаты по возвращённому курсору. При provider_limit_reached пустая выдача может быть неполной. Для поиска по частям следуй narrower_windows и инструкции ответа по сведению исходных A/M/D перед выбором nearest. При подтверждении расходов повторяй с возвращёнными retry_arguments. Сохраняй биржу, символ, ID, единицу контракта, шаг цены и экспирацию.

Для разовой котировки используй marengo_databento_live_get_futures_quote. При выборе по ID передай ID строкой и stype_in=instrument_id. Для потока лучших bid/ask используй marengo_databento_live_stream_bba по его текущей схеме: start, последовательные read по next_cursor, затем stop для того же stream_id. Укажи пропуски missed_events. Пустое чтение при закрытом рынке не даёт новой котировки.

Исторические бары запрашивай через доступную операцию Marengo для OHLCV. Используй покрытие и решения о расходах, возвращённые сервером. При confirmation_required направь владельца в кабинет. При отсутствии прав, подключения или данных сообщи причину. Для опционных греков по запросу доступен scripts/greeks.py (Black-76 для фьючерсных опционов). Указывай входные параметры, время цен и происхождение расчёта.

## Московская биржа

Для текущих котировок используй подключение БКС и его операции чтения. Сопоставь инструмент и режим торгов. Покажи отдельно bid, ask, последнюю сделку и время источника по доступности. Для истории используй доступные исторические свечи БКС либо MOEX ISS с указанием источника. Снимок ISS явно пометь как задержанный. При запросе только live и отсутствии свежих данных БКС сообщи об этом.

## Alpha Vantage

Цены акций США, ETF и самих индексов, FX, криптовалюты и фундаментальные данные запрашивай через отдельный Alpha Vantage MCP. Для цепочки опционов на SPY с греками проверь `REALTIME_OPTIONS` или `HISTORICAL_OPTIONS` на выбранную дату. Если пользователь просит bid/ask конкретного опциона AAPL или другой акции/ETF именно у Alpha Vantage, запроси эту серию через `REALTIME_OPTIONS` с точным идентификатором в поле `contract`, если метод и данные доступны. Укажи bid/ask, возвращённые Alpha Vantage, и время или дату данных. Обозначай их как NBBO только при подтверждении поставщика. При отсутствии котировки сообщи об этом. Подробности приведены в `references/alpha-vantage.md`.

## Ценовой график

Получи исторические свечи выбранным выше маршрутом. Сохрани реальные строки OHLCV в CSV с полями timestamp,open,high,low,close,volume. Приведи цены к денежным единицам согласно схеме источника. Время приведи к UTC (YYYY-MM-DD HH:MM:SS), а для дневных свечей сохрани дату торговой сессии. Используй только доступный интервал или агрегируй более частые свечи. Укажи источник, часовой пояс, диапазон, пропуски и задержку.

Запусти приложенный скрипт из папки скилла, подставив фактические символ, путь к данным, интервал и подпись источника:

```sh
python3 scripts/chart.py SYMBOL --from bars.csv --source-label "SOURCE · UTC" --interval 1d --out price.svg
```

На Windows можно использовать py -3. Передай пользователю полученный SVG. Скрипт рисует ценовые свечи, объём при наличии и SMA-20 при достаточной истории. Для графика достаточно свечей из коннектора, ключи на машине пользователя не требуются. Если среда не позволяет выполнить Python, верни свечи и укажи ограничение построения.
