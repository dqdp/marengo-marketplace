# Установка Marengo на Windows: ChatGPT Work и Claude Cowork

Инструкция для ручной установки под личными аккаунтами. Комплект от 20 ноября 2026 года содержит коннектор **Marengo Data 0.1.4** для ChatGPT и скилл **Marengo Market Data 1.169.2** в редакции с обычными ценовыми графиками. В Claude тот же коннектор подключается по адресу сервера. Настройку и проверку выполните в каждом приложении.

## 1. Что подготовить

| Для чего | Что потребуется |
|---|---|
| Приложения | Настольные ChatGPT с режимом **Work** и Claude с режимом **Cowork**, вход в нужный личный аккаунт в каждом |
| COT и Databento | Приглашённая учётная запись Marengo с правами на COT и Databento. Ключ Databento и действующая подписка владельца нужны для котировок. Публичные отчёты CFTC, ICE и LME доступны через COT без отдельного ключа |
| Первое подключение Claude | **Client ID** и **Client Secret** зарегистрированного приложения Marengo **RC5 Claude MCP**. Их передаёт администратор по защищённому каналу |
| MOEX | Для текущих котировок через БКС — свой токен БКС Trade API с правом **«Только для чтения»** |
| Alpha Vantage | Действующее подключение Alpha Vantage или свои реквизиты у поставщика |
| Обновление скилла из GitHub | [Публичный каталог Marengo](https://github.com/dqdp/marengo-marketplace) доступен по HTTPS без аккаунта GitHub, приглашения, SSH-ключа или доступа к приватным репозиториям. Для установки в ChatGPT через каталог нужны Git и Codex CLI |

1. Установите или обновите настольные приложения. Если используете на Windows тот же аккаунт, что на Linux, сначала посмотрите уже подключённые плагины и выполните проверку из раздела 7. Подключение, которое уже работает, можно сохранить. [ChatGPT Desktop](https://chatgpt.com/download/), [Claude Desktop](https://claude.com/download)
2. Получите у оператора установочный комплект для Windows и распакуйте внешний ZIP в постоянную папку своего профиля, например `Документы\Marengo`. Внутри находятся **Start-here.html**, **marengo-data-0.1.4.zip**, **marengo-market-data-skill-1.169.2.zip** и папка **Work-Marketplace**. Два внутренних ZIP выбираются в соответствующих приложениях целиком.
3. Откройте [личный кабинет Marengo](https://account.marengo.net/) и войдите под приглашённым пользователем. В разделе ключей проверьте Databento. Если ключ ещё не сохранён, введите его в кабинете. Повторное сохранение ключа может сбросить подтверждение покрытия подписки для этого ключа. При необходимости администратор проверяет доступ к коннекторам и подтверждение плана для текущей версии ключа. Дополнительные источники COT, например EIA, используют собственные реквизиты по мере необходимости.
4. Для работы с каталогом ChatGPT установите Git for Windows и Codex CLI под тем же пользователем Windows. Если CLI ещё нет, установите Node.js LTS, откройте обычный PowerShell и выполните команды ниже. После установки программ при необходимости откройте новый PowerShell. [Git for Windows](https://git-scm.com/downloads/win), [Node.js LTS](https://nodejs.org/en/download/), [Codex CLI](https://developers.openai.com/codex/cli)

```powershell
git --version
npm.cmd install --global '@openai/codex@0.155.0'
codex --version
codex plugin marketplace --help
```

Версия 0.155.0 проверена на Windows-раннере. Если уже установлен работающий Codex с командами `plugin marketplace` и `plugin add`, сохраните его. При установке через npm, если PowerShell блокирует запуск обёртки `codex.ps1`, в командах ниже используйте `codex.cmd`.

Для построения ценовых графиков скилл запускает скрипт на Python 3 и создаёт SVG. В Cowork проверьте доступ к выполнению кода и созданию файлов. В Work с локальным исполнением сначала проверьте `py -3 --version` или `python --version` в PowerShell. Если обе команды недоступны в той среде, где должен запускаться график, для локального режима установите [Python для Windows](https://www.python.org/downloads/windows/). Для запросов котировок и отчётов через облачный MCP Python на компьютере клиента не требуется.

## 2. Marengo MCP в ChatGPT Work

1. Откройте настольный ChatGPT и переключитесь в **Work**. Откройте **Plugins** и проверьте **Marengo Data** среди своих плагинов. Если он уже установлен, откройте его и проверьте статус подключения.
2. Для новой установки используйте предоставленный **marengo-data-0.1.4.zip**. В каталоге плагинов выберите **Add (+)** и загрузку плагина из ZIP, если она доступна. Если **Add** открывает **Plugin Creator**, приложите тот же архив и попросите создать личный приватный плагин из готового пакета с сохранением включённой конфигурации MCP и OAuth. Установите полученный **Marengo Data** в своём аккаунте. Если в аккаунте отсутствуют оба пути, оператору нужно передать доступный этому аккаунту способ установки приватного плагина. [Установка и создание плагинов в ChatGPT](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt)
3. Нажмите **Connect** и войдите на странице Marengo. Подтвердите доступ, включая продление после закрытия приложения, если это указано в форме. Пакет уже содержит адрес `https://mcp.marengo.net/mcp` и публичный идентификатор OAuth-клиента ChatGPT. Поля **Client Secret** для этого пакета заполнять не требуется.
4. В новом чате **Work** выберите **Marengo Data** в меню инструментов и отправьте: «Через Marengo вызови `marengo_platform_catalog`. Какие коннекторы мне доступны?» Для пользователя с обоими правами ожидаются `cot` и `databento`.

**Marengo Data** предоставляет инструменты. **Marengo Market Data** из раздела 4 добавляет правила выбора источника и ценовые графики. В списке плагинов ChatGPT допустимы оба названия.

## 3. Marengo MCP в Claude Cowork

1. В настольном Claude откройте **Customize → Connectors**. Если **Marengo** уже есть, нажмите **Connect**, когда это предложено, и перейдите к проверке. [Страница коннекторов Claude](https://claude.ai/customize/connectors)
2. При первой установке нажмите **+ Add → Add custom connector**. Имя — **Marengo**, **Remote MCP server URL** — `https://mcp.marengo.net/mcp`. Нажмите **Continue**.
3. Выберите **Sign in now → Use your own OAuth client**. Введите **Client ID** и **Client Secret** приложения **RC5 Claude MCP** в поля Claude. Для того же сервера и приложения на другом компьютере подходят те же Client ID и действующий Client Secret. Если администратор заменил секрет, используйте новый. Поле дополнительных заголовков Marengo оставьте пустым.
4. Нажмите **Add**. При установке клиенту на странице Marengo он входит под своей приглашённой учётной записью и подтверждает доступ. При установке для себя войдите в свою учётную запись Marengo. Откройте новый чат **Cowork**, выберите **+ → Connectors → Marengo** и отправьте тот же запрос каталога, что в Work. [Инструкция Anthropic](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)

**Для администратора Marengo.** Если реквизиты Claude нужно получить заново, откройте защищённую консоль Logto, выберите **Default tenant → Applications → Third-party applications → RC5 Claude MCP → Settings → Endpoints & Credentials**. Скопируйте **App ID** и действующий **App secret**. В зарегистрированных redirect URI должен быть `https://claude.ai/api/mcp/auth_callback`. В нашей установке консоль доступна через SSH-туннель. Оператор с доступом к серверу может открыть его из PowerShell командой ниже, подставив своего пользователя и адрес сервера. Пока терминал открыт, откройте [консоль Logto](http://localhost:3002) в браузере этого компьютера. После настройки завершите туннель сочетанием Ctrl+C. Клиенту для обычной работы достаточно учётной записи Marengo. [Настройки приложения Logto](https://docs.logto.io/quick-starts/traditional-web)

```powershell
ssh -4 -N -o ExitOnForwardFailure=yes -L 127.0.0.1:3002:127.0.0.1:3002 USER@SERVER
```

## 4. Скилл Market Data в ChatGPT Work

**Установка из публичного каталога GitHub с возможностью обновления.** В PowerShell выполните команды по одной. Если какая-либо команда завершилась ошибкой, сначала устраните её. На дату инструкции `main` ещё содержит прежнюю 1.168.0, а **1.169.2** находится в ветке ниже. После включения нужной версии в `main` для новых установок используйте `--ref main`. [PR и состояние поставки](https://github.com/dqdp/marengo-marketplace/pull/1)

```powershell
git ls-remote --exit-code https://github.com/dqdp/marengo-marketplace.git refs/heads/docs/personal-install-light-skill
codex plugin marketplace list --json
```

Команда `git ls-remote` должна вывести ветку и хеш коммита без входа в GitHub. Если каталога `marengo` ещё нет, выполните следующие команды.

```powershell
codex plugin marketplace add https://github.com/dqdp/marengo-marketplace.git --ref docs/personal-install-light-skill
codex plugin list --marketplace marengo --available --json
codex plugin add marengo-market-data@marengo
codex plugin list --marketplace marengo --json
```

В последней команде найдите `marengo-market-data@marengo`, `version: 1.169.2`, `installed: true` и `enabled: true`. Для новой установки оставьте HTTPS. Если на вашем старом компьютере уже работает SSH, его можно сохранить.

**Если появляется `marketplace 'marengo' is already added from a different source`.** Посмотрите источник через `codex plugin marketplace list --json`, установленные плагины через `codex plugin list --marketplace marengo --json` и доступную версию через `codex plugin list --marketplace marengo --available --json`.

- Если уже установлена и включена 1.169.2, перейдите к проверке в Work. Если версия доступна для установки, установите или обновите плагин из этого каталога и сверьте результат.
- Если источник — этот же репозиторий, но старая ветка, запишите прежний URL, ветку и версию для отката. Если единственная запись в `installed` — старая версия `marengo-market-data@marengo`, выполните `codex plugin remove marengo-market-data@marengo`. Команда удаляет локальную копию именно этого плагина. Снова выполните `codex plugin list --marketplace marengo --json`.
- Когда список `installed` пуст, выполните `codex plugin marketplace remove marengo`, затем повторите установку из нужной ветки выше или из папки комплекта ниже. Если в списке остаются другие плагины либо URL относится к другому репозиторию, сохраните их текущую регистрацию и передайте оператору имена и источник для совместимой настройки.

**Установка из комплекта, если GitHub недоступен клиенту.** Откройте PowerShell прямо в распакованной папке комплекта и на чистом профиле выполните:

```powershell
codex plugin marketplace add (Resolve-Path .\Work-Marketplace).Path
codex plugin add marengo-market-data@marengo
codex plugin list --marketplace marengo --json
```

Оставьте папку **Work-Marketplace** на диске. Для этой установки следующую версию поставляет оператор. Для Git-источника каталог обновляется командой `codex plugin marketplace upgrade marengo` в пределах выбранной ветки. Затем откройте карточку плагина, примените обновление, если оно предложено, и проверьте версию командой `plugin list`.

Полностью закройте и откройте ChatGPT. В режиме **Work → Plugins → Marengo** откройте **Marengo Market Data** и проверьте, что он включён. Для проверки используйте новый чат. [Каталоги плагинов в настольном ChatGPT](https://developers.openai.com/plugins/build/plugins#add-a-marketplace-from-the-cli)

## 5. Скилл Market Data в Claude Cowork

**Установка версии 1.169.2.**

1. Откройте **Customize → Skills → + → Create skill → Upload a skill**.
2. Выберите **marengo-market-data-skill-1.169.2.zip** из комплекта или [скачайте тот же ZIP из публичного каталога](https://raw.githubusercontent.com/dqdp/marengo-marketplace/be60fcb9f14c9d98920316ec2663b823b0ff82d2/downloads/marengo-market-data-skill-1.169.2.zip). Внутри него папка `market-data` с `SKILL.md`, справочником Alpha Vantage и скриптами графика и греков. Если Claude сообщает о совпадении имени с вручную загруженным скиллом, сохраните прежний ZIP и замените только эту копию через её карточку.
3. Включите появившийся **market-data**, откройте новый чат **Cowork** и оставьте включённой одну самостоятельную редакцию Market Data. [Загрузка скиллов в Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

**Обновления из GitHub.** Когда в `main` публичного каталога будет 1.169.2 или нужная более новая редакция, откройте **Customize → Plugins → Add → Add marketplace → Add from a repository**. Укажите `dqdp/marengo-marketplace` и установите **Marengo Market Data**. Если Claude предложит подключить GitHub к самому приложению, альтернативой остаётся публичный ZIP. Сверьте версию, затем выключите вручную загруженную копию. У ZIP-копии обновление выполняется повторной загрузкой. [Каталоги плагинов Claude](https://support.claude.com/en/articles/13837440-use-plugins-in-claude)

## 6. БКС для MOEX и Alpha Vantage

**БКС.** Для живого bid/ask Московской биржи скилл предпочитает БКС. В личном кабинете БКС откройте **Профиль → Счета и тарифы → нужный счёт → Токены API → Выпустить токен** и выберите **«Только для чтения»**. Скопируйте refresh-токен БКС в настройки каждого клиента.

| Где | Действия |
|---|---|
| ChatGPT Desktop | **Настройки → Интеграции → Плагины → Добавить → Добавить сервер MCP**. Имя **БКС**, тип **Потоковая передача HTTP**, URL `https://be.broker.ru/trade-api-mcp-server/mcp`. В заголовках укажите имя `Authorization` и значение `Bearer ВАШ_ТОКЕН_БКС`, с одним пробелом |
| Claude Desktop / Cowork | **Customize → Connectors → + Add → Add custom connector**, то же имя и URL. Выберите **No sign-in**, в **Request headers** задайте тот же заголовок и оставьте **Required**. Нажмите **Add** и включите БКС в новом чате |

Если ваша версия Claude не показывает **Request headers**, у БКС есть отдельная инструкция для Windows через **Settings → Developer → Edit Config** и локальный `mcp-remote`. Используйте её как альтернативный способ подключения **только БКС**, сохраните остальные записи конфигурации. Токен вводится в настройках, а не в тексте запроса модели. [Официальная инструкция БКС для ChatGPT Desktop и Claude Desktop](https://trade-api.bcs.ru/mcp/)

**Alpha Vantage.** Если прежний официальный коннектор работает, сохраните его и проверьте запросом SPY. На чистой установке в **ChatGPT → Plugins/Apps** найдите **Alpha Vantage**, выберите официальный коннектор и **Connect**. В **Claude → Customize → Connectors** найдите **Alpha Vantage MCP Server** в каталоге и нажмите **Connect**. Завершите OAuth у Alpha Vantage; если поставщик запросит ваш API key, введите его в форме поставщика. Официальный адрес удалённого MCP — `https://mcp.alphavantage.co/mcp`. Доступность real-time US equities определяется тарифом Alpha Vantage. [Подключение у Alpha Vantage](https://mcp.alphavantage.co/), [коннектор в каталоге Claude](https://claude.com/marketplace/connectors/alpha-vantage)

## 7. Как принять установку

Запустите эти проверки **отдельно в новом чате ChatGPT Work и в новом чате Claude Cowork**. Для проверки обновления доступа повторите запрос каталога после истечения исходного токена; у ресурса Marengo его срок на дату инструкции составлял один час.

| Что проверить | Что написать | Признак успеха |
|---|---|---|
| Доступ и COT | «Вызови `marengo_platform_catalog`, затем `marengo_cot_data_catalog` через Marengo» | Оба инструмента выполнились. Пустой кэш нового пользователя сам по себе допустим |
| Databento | «Используй Marengo Market Data. Получи лучший bid и ask по ES через Marengo Databento, покажи контракт, источник и время события» | В ответе две стороны рынка, идентификатор контракта и время события. Для CME источник `GLBX.MDP3`. Если рынок закрыт, повторите в торговую сессию |
| Ценовой график | «Построй обычный ценовой график ES по доступным минутным свечам за 30 минут завершённой сессии. Покажи источник и часовой пояс» | Появился график с инструментом и периодом. Для истории вне подписки при денежном подтверждении можно остановить проверку |
| MOEX | «Покажи текущие лучшие bid и ask SBER через БКС, укажи время» | Указаны БКС и время котировки. Ответ MOEX ISS с задержкой распознаётся как другой источник |
| Alpha Vantage | «Получи SPY через официальный Alpha Vantage и укажи время цены» | Указан Alpha Vantage, получены цена и время в рамках тарифа |

Поток BBA и расширенный поиск контрактов проверяйте только если их объявляет каталог текущего Gateway. Успех разового bid/ask подтверждает получение одного обновления. Денежное подтверждение для покрытой истории зависит от серверной привязки подписки к текущему ключу; сохраните диагностическое сообщение, если поведение расходится с ожидаемым.

## 8. Что сделать со старым скиллом и локальными MCP

| Старый компонент | Как перейти |
|---|---|
| Самостоятельный **Market Data** из старого ZIP или старого плагина | После установки 1.169.2 выключите прежнюю редакцию при проверочных запросах. Когда новая версия пройдёт проверку в обоих клиентах, старый скилл можно удалить из их списков. Для отката сохраните старый ZIP отдельно. Если скилл был распакован в личный каталог `skills`, переместите только его папку из каталога обнаружения в резервную папку |
| Локальные **Databento MCP** и **COT MCP** | Сначала запишите их имена, способ запуска и пути к данным. Отключите старые подключения в каждом клиенте и выполните раздел 7 через облачный Marengo. Установленные программы можно пока оставить для отката. Удаление программ имеет смысл после проверки, что другие проекты и локальные сценарии ими больше не пользуются |
| Новый **Marengo Data** и **Marengo Market Data** | Оба остаются подключёнными в Work. Первый даёт MCP-инструменты и содержит свой короткий встроенный `market-data`; второй выбирает источники и строит графики. Проверяйте название плагина-владельца перед отключением одноимённых скиллов. В Cowork сохраняются коннектор **Marengo** и новый **market-data** |
| **БКС** и **Alpha Vantage** | Оставьте рабочие подключения. Для БКС достаточно одного способа подключения в каждом клиенте |

В Claude локальный сервер мог быть добавлен как **Desktop Extension** или записью в `%APPDATA%\Claude\claude_desktop_config.json`. Для расширения используйте его выключатель. Для ручной записи сначала сделайте приватную резервную копию файла, затем уберите только соответствующий ключ в `mcpServers`, сохранив корректный JSON и остальные серверы. Полностью выйдите из Claude через значок в системном трее и запустите его снова. В ChatGPT/Codex проверьте **Plugins / MCP** и отдельные записи пользовательской конфигурации. Перед изменением ручной конфигурации сохраните её приватную копию. Резервные копии могут содержать ключи.

**Локальные базы COT, кэши, отчёты и оригиналы Databento сохраните.** Облачный профиль Marengo имеет собственный кэш. Локальные данные автоматически в него не переносятся. Если нужен старый локальный материал, сохраните доступ к нему и проверьте чтение до любой деинсталляции. Брокерские токены, подписка Databento и рабочие ключи других проектов сохраняют самостоятельное назначение.

## 9. Если что-то не работает

- **Marengo виден, инструментов нет.** Проверьте **Connect**, включение инструмента в конкретном новом чате, личную учётную запись и права на нужный коннектор. Если каталог открывается, а Databento недоступен, проверьте ключ и доступ к dataset в кабинете Marengo.
- **Снова просит войти через час.** Отметьте приложение и время, проверьте именно этот OAuth-клиент и выдачу `offline_access` у администратора. Обычное продление происходит автоматически при действующем refresh token. Истёкшее или отозванное согласие требует нового входа. Не открывайте старую ссылку авторизации от другой попытки.
- **Скилл есть, но отвечает старый локальный сервер.** Посмотрите поставщика фактически вызванного инструмента, выключите старую запись, начните новый чат и повторите тест с явным названием **Marengo**.
- **На другом компьютере скилл не появился.** Для локального каталога Work установка делается под пользователем Windows на этом ПК. Проверьте `codex plugin list --marketplace marengo --json`, затем перезапустите настольный ChatGPT.
